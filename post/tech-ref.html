Technology Reference Tools for Learners

  • School library catalog: Use the district’s catalog link to search for materials by title, author, subject, genre, or format. Compare search results with what you notice in the library, and record how the catalog helps—or does not help—you find materials.
  • MARVEL! Maine State Library databases Use the databases to find reliable articles and information that may help you investigate library trends and user needs. Check source details and use only information relevant to your project question.
  • Google Scholar Search for research on library design, reading engagement, and related topics. Use the results as background evidence, and check publication details and source quality before drawing conclusions.
  • Library of Congress Explore primary sources and collections for display inspiration or possible library activities. Record the source of any material you use in a proposal or prototype.
